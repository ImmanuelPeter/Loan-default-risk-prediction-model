Class Imbalance Mitigation (Credit Default Ratios)
Cost-Sensitive Weighting

In standard retail credit datasets, the vast majority of loans are successfully repaid (~82.5%), while default occurrences constitute the minority class (~17.5%).

Without class balancing, naive models may predict "Non-Default" 100% of the time, achieving deceptive 82.5% accuracy but catastrophic financial risk exposure.

Applied Solution: Inverse Frequency Class Weights \(\frac{N_{total}}{2 \times N_k}\). Default class errors are penalized with 4.71× higher gradient penalty during loss optimization.

Dataset Class Distribution

Non-Default (Class 0 - Repaid) 82.5% (8,250 loans)
Default (Class 1 - Defaulted) 17.5% (1,750 loans)
